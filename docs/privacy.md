# Privacy Policy — Video2Sale

Last updated: May 17, 2026

## 1. Data We Collect

- TikTok public product data (names, categories, metrics) via TikTok APIs
- User-generated content (video scripts, prompts) stored locally
- No personal data from TikTok users is collected or stored

## 2. How We Use Data

- Product discovery: identifying trending products for affiliate content creation
- Performance tracking: monitoring video metrics for the creator's own account
- Content generation: creating video scripts based on product information

## 3. Data Storage and Retention

- All data is stored locally on the user's own infrastructure
- TikTok API data is retained for a maximum of 30 days
- Users can delete their data at any time

## 4. Data Sharing

- We do NOT sell, rent, or share any data with third parties
- No data is transmitted to external servers beyond TikTok's own APIs

## 5. TikTok Data Compliance

- We comply with TikTok's Developer Terms of Service
- We only access data through official TikTok APIs
- We respect rate limits and data usage policies
