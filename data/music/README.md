# Músicas de Fundo

Coloque aqui arquivos `.mp3` ou `.wav` royalty-free para usar como fundo nos vídeos.

O sistema seleciona aleatoriamente uma track para cada vídeo.

## Fontes gratuitas recomendadas

- https://pixabay.com/music/ (CC0, uso comercial)
- https://www.bensound.com/free-music-for-videos (Creative Commons)
- https://freemusicarchive.org/ (vários licenças)

## Requisitos

- Formato: MP3 ou WAV
- Duração: 30s+ (será cortado automaticamente)
- Estilo: energético, TikTok-friendly, sem vocal
- Volume: será reduzido a 12-20% automaticamente

## Exemplo de nome

```
upbeat-tiktok-01.mp3
energetic-promo-02.mp3
chill-review-03.mp3
```
