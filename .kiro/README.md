# Video2Sale - orientacao canonica

O objetivo deste repositório é aumentar o lucro obtido pelo proprietário com
conteúdo de TikTok Shop. O aplicativo é uma ferramenta interna, local e
single-user. Ele não é um SaaS e não deve ser planejado como produto para
terceiros.

## Documentos ativos

- `steering/product-focus.md`: regras permanentes para toda alteração.
- `specs/internal-profit-engine/requirements.md`: requisitos e critérios de sucesso.
- `specs/internal-profit-engine/design.md`: arquitetura-alvo da refatoração.
- `specs/internal-profit-engine/tasks.md`: sequência executável de trabalho.

## Documentos legados

Os arquivos `mvp-affiliate-video-factory*.md` registram explorações anteriores.
Eles não definem mais o escopo atual e não devem ser usados para gerar backlog.

Em caso de conflito, a ordem de precedência é:

1. `steering/product-focus.md`
2. a spec `internal-profit-engine`
3. código e documentação ativos
4. documentos legados
